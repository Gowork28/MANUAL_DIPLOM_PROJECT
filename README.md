# Ручное тестирование веб-приложения Яндекс Самокат (дипломная работа)

Яндекс Самокат - это сервис аренды самокатов. Самокат доставляет курьер в указанный день. Можно выбрать цвет самоката и срок аренды.

# Задачи:
- составить чек-лист к экрану "Статус заказа"
- проверить корректность валидации полей для экрана "Сделать заказ"
- провести полное функциональное тестирование по оставшимся макетам и требованиям
- спроектировать тест-кейсы функциональностей "Нотификация с напоминанием о доставке самоката" и "Уведомление об отсутсвии интернет-соединения"
- составить баг-репорты
